Trusted resources

The high-trust sources this course is built from. Knowledge in lessons is drawn from here — not from memory.

Knowledge — SQL & MySQL

  • MySQL 8.0 Reference Manual — the primary source for exact syntax and behaviour. Reach for it whenever MySQL-specific behaviour matters.
  • SQLBolt — interactive SQL lessons — browser-based, no setup, instant feedback. Best for drilling SELECT/JOIN/aggregation until automatic.
  • Mode SQL Tutorial — clear, basic-to-advanced (incl. window functions). A solid second explanation when something hasn't clicked.
  • "Use The Index, Luke!" — Markus Winand — the definitive developer's guide to indexing and the B-tree. For indexes, EXPLAIN, and why a query is slow.
  • Select Star SQL — free interactive book that builds real query skill on one dataset. Great for spaced retrieval practice.

Knowledge — Data pipelines & modeling

  • _Designing Data-Intensive Applications_ — Martin Kleppmann — the canonical text on how data systems work: storage, replication, batch vs stream, CDC.
  • _The Data Warehouse Toolkit_ — Kimball & Ross — the standard reference for dimensional modeling (star schema, facts/dimensions).
  • dbt docs — modern ELT and transformation-in-the-warehouse practice; idempotent transforms and data testing.

Wisdom — communities

  • r/SQL — active and beginner-friendly; strong on query help and interview-prep threads.
  • r/dataengineering — high-signal on pipelines, warehouses, and what's actually used in industry.
  • DBA Stack Exchange — expert-moderated Q&A for database internals, indexing, and locking.

Interview practice — drilling grounds

  • DataLemur — real-company SQL questions, tiered by difficulty.
  • StrataScratch — SQL + data interview problems from real companies.
  • LeetCode — Top SQL 50 — focused JOIN/window practice under constraints.
