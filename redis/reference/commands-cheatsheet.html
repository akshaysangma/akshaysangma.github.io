Redis — Command Cheat-Sheet

Every command the course touches, grouped by data type, each with its worst-case Big-O and a one-line purpose. Built for Redis 7.x. Print it, pin it, reach for the right call on instinct. Back to the course map.

Reading the Big-O: N = elements in the involved collection unless noted; M = elements actually returned or touched; K = number of keys/sets. Aggregate-type reads/writes that "do one thing" (e.g. HGET, SISMEMBER) are O(1) on hash-table encodings — small collections may be packed (listpack/intset) and scan linearly instead. Pills mark the version a command or flag arrived in.
