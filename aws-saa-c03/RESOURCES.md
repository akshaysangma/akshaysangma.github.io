# AWS Certified Solutions Architect – Associate (SAA-C03) Resources

> High-trust sources only. Knowledge in lessons is drawn from here, not from memory.

## Knowledge — Official (primary sources)

- [SAA-C03 Exam Guide (AWS, official)](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.html)
  The authoritative blueprint: domains, weightings, task statements, in-scope/out-of-scope service lists. Use for: deciding what to study and how much. The single source of truth — everything else is commentary on this.
- [SAA-C03 Exam Guide PDF](https://docs.aws.amazon.com/pdfs/aws-certification/latest/solutions-architect-associate-03/solutions-architect-associate-03.pdf)
  Printable version of the above. Use for: offline review of task statements.
- [Certification landing page](https://aws.amazon.com/certification/certified-solutions-architect-associate/)
  Logistics, exam fee, scheduling (Pearson VUE), official practice question set. Use for: booking the exam, official sample questions.
- [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html)
  The conceptual spine of the whole exam. Six pillars; four map directly onto the exam domains. Use for: the lens you apply to *every* scenario question.
- [AWS Skill Builder — Exam Prep: SAA-C03 (official, free tier)](https://skillbuilder.aws/exam-prep/aws-certified-solutions-architect-associate)
  AWS's own prep plan, including a free official practice question set and an Official Practice Exam. Use for: realistic question style and final readiness check.
- [AWS Documentation FAQs (per service)](https://aws.amazon.com/faqs/)
  e.g. S3 FAQ, EC2 FAQ, VPC FAQ. Use for: authoritative service limits, behaviours, and edge cases the exam loves.

## Knowledge — Trusted third-party (to be vetted as we go)

- [Pluralsight / Adrian Cantrill course (paid)](https://learn.cantrill.io/) — widely regarded as the most thorough SAA-C03 video course. Use for: deep conceptual grounding if a topic won't stick. *(Optional given timeline.)*
- [Tutorials Dojo — practice exams & cheat sheets (paid, Jon Bonso)](https://tutorialsdojo.com/aws-certified-solutions-architect-associate-saa-c03/) — the most recommended practice-exam bank; question style closely mirrors the real exam. Use for: timed practice and the "comparison of services" cheat sheets.

## Wisdom (Communities)

- [r/AWSCertifications](https://www.reddit.com/r/AWSCertifications/) — high-volume subreddit of people sitting the same exams. Use for: study-plan critique, "is this resource still current", exam-day logistics, recent question-style reports.
- [AWS re:Post](https://repost.aws/) — AWS's official Q&A community. Use for: clarifying *why* a service behaves a certain way when docs are ambiguous.
