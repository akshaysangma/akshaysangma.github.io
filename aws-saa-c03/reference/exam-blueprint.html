Domains & weighting

Four domains. Each maps to a pillar of the Well-Architected Framework. Spend study time roughly in proportion to weight.

Source: AWS SAA-C03 Exam Guide content outline.

Why this matters Security is nearly a third of the exam. If you're triaging study time, IAM, encryption, network security (security groups / NACLs / VPC), and data protection earn the most marks per hour.

Task statements per domain (study checklist)

The exam guide expands each domain into task statements. Use these as a self-audit — can you reason about a scenario in each?

Domain 1 — Secure (30%)

  • Design secure access to AWS resources (IAM users/roles/policies, identity federation, least privilege).
  • Design secure workloads & applications (VPC security: security groups, NACLs, network segmentation).
  • Determine appropriate data security controls (encryption at rest/in transit, KMS, secrets management).

Domain 2 — Resilient (26%)

  • Design scalable & loosely coupled architectures (SQS, SNS, ELB, Auto Scaling, decoupling).
  • Design highly available & fault-tolerant architectures (Multi-AZ, multi-Region, backups, RTO/RPO).

Domain 3 — High-Performing (24%)

  • Determine high-performing/scalable storage (S3 classes, EBS types, EFS, FSx).
  • Design high-performing/elastic compute (EC2 families, Lambda, containers, Auto Scaling).
  • Determine high-performing database solutions (RDS, Aurora, DynamoDB, ElastiCache, read replicas).
  • Determine high-performing/scalable networking (CloudFront, Global Accelerator, caching).
  • Determine high-performing data ingestion/transformation (Kinesis, Glue, etc.).

Domain 4 — Cost-Optimized (20%)

  • Design cost-optimized storage (S3 lifecycle/Intelligent-Tiering, EBS right-sizing).
  • Design cost-optimized compute (Spot, Reserved, Savings Plans, right-sizing, serverless).
  • Design cost-optimized database & network (data transfer costs, NAT vs gateway endpoints).
