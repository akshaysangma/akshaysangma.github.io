Service Tiers & Properties

Your cram core: the service names, tiers, and distinguishing properties the SAA-C03 turns into questions. Built because the reasoning lens only works once you know the facts to feed it.

How to use these Don't read them like prose. Pick one table, cover the right column, and recall the property from the service name (and vice-versa). The exam tests the distinguishing property — the one fact that separates two similar services (retrieval time, AZ count, stateful vs stateless, sync vs async).

The dozen distinctions most likely to decide a question

  1. S3 Deep Archive = cheapest but hours to retrieve; Glacier Flexible = minutes–hours; Glacier Instant = milliseconds.
  2. One Zone-IA / Express One Zone = single AZ (no AZ resilience); everything else ≥3 AZs.
  3. EBS = one instance, one AZ; EFS = many Linux instances, multi-AZ; Instance Store = ephemeral.
  4. gp3 = default SSD, IOPS/throughput decoupled from size; io2 = mission-critical, 99.999%.
  5. Spot = interruptible/fault-tolerant only; Reserved/Savings Plans = steady-state.
  6. ALB = HTTP path/host routing; NLB = TCP/UDP, static IP, extreme scale.
  7. Multi-AZ = availability/failover; Read Replica = read scaling.
  8. DynamoDB single-digit ms; DAX microseconds; Global Tables multi-region active-active.
  9. Redis = persistent/failover/rich; Memcached = simple/multi-threaded cache.
  10. Security Group stateful (allow only); NACL stateless (allow + deny).
  11. Gateway Endpoint = free, S3/DynamoDB only; Interface Endpoint = paid ENI, everything else.
  12. SQS decouple; SNS fan-out; EventBridge event patterns; Kinesis ordered replayable streams.
