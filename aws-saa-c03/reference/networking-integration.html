Networking & Integration — Properties

VPC, Route 53, content delivery, hybrid connectivity, and messaging. Verified against AWS docs (Jun 2026).

Security Groups vs Network ACLs

The single most-tested VPC comparison.
FeatureSecurity GroupNetwork ACL
LevelInstance (ENI)Subnet
StateStateful (return traffic auto-allowed)Stateless (must allow return explicitly)
RulesAllow onlyAllow and Deny
EvaluationAll rulesNumbered order, first match wins
Exam tell "Return traffic allowed automatically" = Security Group. "Explicitly block a specific IP" = NACL (only NACLs have Deny).

VPC connectivity

ComponentKey facts / exam tell
NAT GatewayManaged, HA per AZ, up to 100 Gbps; outbound internet for private subnets. (NAT Instance = self-managed, legacy, supports port-forwarding/bastion)
VPC Peering1:1 private link; NOT transitive (A–B + B–C ≠ A–C)
Transit GatewayHub-and-spoke, transitive; connect many VPCs + on-prem. "3+ VPCs need to talk" → TGW
Gateway EndpointFree; route-table based; S3 & DynamoDB only
Interface Endpoint (PrivateLink)ENI in subnet, hourly + data cost; all other services (SQS, SNS, EC2, API GW…)
VPC Flow LogsCapture accept/reject traffic → CloudWatch/S3/Firehose (troubleshooting, security)

Route 53 routing policies

LatencyLowest-latency region

Alias vs CNAME: Alias points to AWS resources, is free, and works at the zone apex (e.g. example.com). CNAME can't be used at the apex. "Point example.com to CloudFront/ALB" → Alias.

Content delivery & acceleration

ServiceUse when
CloudFrontCache static/dynamic content at edge (HTTP/HTTPS). Protect S3 origin with OAC. Signed URLs/cookies for private content
S3 Transfer AccelerationSpeed up uploads to S3 from far away (via edge)
Global AcceleratorAnycast static IPs, TCP/UDP (non-HTTP), multi-region failover. Gaming/VoIP/IoT

CloudFront = caching, HTTP only. Global Accelerator = no caching, any protocol, static IPs, fast multi-region failover.

Application integration / messaging

The "which messaging service" decision is heavily tested.
SQSSNSEventBridgeKinesis
ModelQueue (pull)Pub/sub (push)Event bus + rulesStreaming
PatternDecouple, bufferFan-out to manyRoute by event patternReal-time, ordered, replayable
RetentionUp to 14 daysNone (real-time)None24 h (up to 365 d)
DetailFact
SQS StandardAt-least-once, best-effort order, unlimited throughput
SQS FIFOExactly-once, strict order; up to 3,000 msg/s with batching
SQS visibility timeoutDefault 30 s (0–12 h); long polling up to 20 s; DLQ for poison messages
SNSFan-out to SQS / Lambda / HTTP / email / SMS; filter policies; Standard & FIFO topics
Amazon MQManaged ActiveMQ/RabbitMQ — migrate legacy apps using JMS/AMQP/MQTT without rewrite
Kinesis Data StreamsReal-time, sharded (1 MB/s in, 2 MB/s out per shard), per-shard order, replayable
Kinesis Data FirehoseManaged delivery to S3/Redshift/OpenSearch; near-real-time, no code
EventBridgeEvent bus, pattern matching, SaaS & AWS event sources; Pipes for point-to-point
Step FunctionsOrchestrate multi-step workflows (Standard up to 1 yr; Express high-volume, ≤5 min)
Messaging tells Decouple two services → SQS. One message to many subscribers → SNS (often SNS→SQS fan-out). React to events by pattern → EventBridge. Ordered, replayable real-time stream → Kinesis. Legacy broker protocol → Amazon MQ.
