Breadth Services — The Long Tail

One-liner recognition for the services that show up as single-answer "which service does X?" questions. Read the right column, name the service. That's the whole skill here.

How to use this sheet These are recognition-level. Don't over-study them — one line each is enough to answer a "which service does X" question. The Lessons cover everything that needs depth.

Analytics

ServiceWhat it is / use when
AWS GlueServerless ETL plus a central Data Catalog — discover, transform, and prepare data without managing servers.
Amazon EMRManaged big-data platform for Hadoop, Spark, Hive, Presto — heavy distributed processing on clusters.
Amazon OpenSearch ServiceManaged search and log analytics (the ELK successor) — full-text search, dashboards, log exploration.
Amazon QuickSightServerless BI — interactive dashboards and visualizations over your data sources.
Amazon MSKManaged Apache Kafka — when the requirement explicitly says "Kafka" for streaming/event pipelines.
AWS Lake FormationBuild and govern a data lake on S3 — centralized permissions and access control over lake data.
Amazon Kinesis Video StreamsSecurely stream video from connected devices to AWS for analytics, ML, and playback.
AWS Data ExchangeMarketplace to find, subscribe to, and use third-party datasets in the cloud.

Compute & Containers (extras)

ServiceWhat it is / use when
AWS Elastic BeanstalkPaaS — just deploy your app code and AWS provisions and manages the underlying infra for you.
AWS BatchManaged batch computing — schedule and run large numbers of batch jobs without managing the queue/compute.
Amazon ECRManaged Docker/OCI container image registry — store and pull images for ECS/EKS.
AWS OutpostsGenuine AWS hardware racks run on-premises — same APIs and services locally for low-latency / data-residency needs.
AWS WavelengthAWS compute embedded in 5G carrier networks — ultra-low latency for mobile and edge apps.
VMware Cloud on AWSRun your existing VMware vSphere environment natively on AWS infrastructure.

Developer / Operations

ServiceWhat it is / use when
AWS X-RayDistributed tracing — trace and debug requests as they hop across microservices.
AWS License ManagerTrack and enforce software license usage (BYOL) across AWS and on-prem.
AWS Service CatalogCurated catalog of approved, governed products that users can self-provision.
Amazon Managed GrafanaFully managed Grafana — visualization and dashboards over operational metrics.
Amazon Managed Service for PrometheusManaged Prometheus-compatible monitoring for container/metrics workloads at scale.

Machine Learning / AI

ServiceWhat it is / use when
Amazon RekognitionImage and video analysis — object/face detection, content moderation.
Amazon ComprehendNLP — sentiment, entities, key phrases, and language from text.
Amazon TranscribeSpeech → text (automatic transcription of audio).
Amazon PollyText → speech (lifelike voice synthesis).
Amazon TranslateNeural machine translation between languages.
Amazon TextractExtract text, forms, and tables from scanned documents (OCR+).
Amazon LexBuild conversational chatbots (the voice/text engine behind Alexa).
Amazon KendraIntelligent, ML-powered enterprise search over your documents.
Amazon SageMakerEnd-to-end platform to build, train, and deploy custom ML models.

Migration & Transfer (extras)

ServiceWhat it is / use when
AWS Application Migration Service (MGN)Lift-and-shift entire servers (rehost) to AWS with minimal changes.
AWS DMSDatabase Migration Service — migrate/replicate databases, including across engines. See Lesson 11 for depth.
AWS Snow FamilyPhysical devices for petabyte-scale offline / edge data transfer. See Lesson 3 for depth.

Front-end / Integration (extras)

ServiceWhat it is / use when
AWS AmplifyFull-stack hosting and tooling for web/mobile apps — front-end deploy plus backend wiring.
AWS AppSyncManaged GraphQL API — single endpoint over multiple data sources, with real-time/offline sync.
Amazon AppFlowNo-code data integration between SaaS apps (Salesforce, etc.) and AWS services.
Amazon CognitoUser sign-up/sign-in and identity for apps. See Lesson 14 for depth.
