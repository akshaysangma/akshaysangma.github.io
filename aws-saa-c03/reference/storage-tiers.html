Storage — Tiers & Properties

S3 classes, EBS volumes, file systems, gateways, and migration. The numbers in bold are the ones the exam turns into traps. Verified against AWS docs (Jun 2026).

The trap that got you on Lesson 1 Q1 "Cheapest" is necessary but not sufficient — always check retrieval time against the scenario's access need. Deep Archive is cheapest but retrieves in hours; if the scenario says "within minutes", you need Glacier Flexible (or Instant) Retrieval instead.

S3 storage classes

All classes are 11 nines (99.999999999%) durability. They differ on AZ count, retrieval latency, minimum duration, and cost. Memorize the retrieval time column — it's the most-tested.

S3 features the exam tests

FeatureOne-line tell
Lifecycle rulesAuto-transition to cheaper classes & expire after N days (transitions follow the cost waterfall only).
VersioningKeeps multiple versions; protects against delete/overwrite. Once enabled, can only be suspended, not removed.
MFA DeleteRequires MFA to delete a version or change versioning state. Root/bucket-owner only.
Replication (CRR / SRR)Async copy. CRR = cross-Region (DR, compliance, latency); SRR = same-Region (log aggregation, prod→test). Both need versioning on source + destination.
Transfer AccelerationUploads routed through CloudFront edges over AWS backbone — fast long-distance uploads.
SSE-S3Server-side, S3-managed AES-256 keys. Default, zero key management.
SSE-KMSServer-side with KMS keys — adds audit trail (CloudTrail), key policies, rotation.
SSE-CCustomer-provided keys; AWS encrypts but never stores the key.
DSSE-KMSDual-layer KMS encryption for high-compliance (e.g. DoD) workloads.
Object Lock (WORM)Write-once-read-many. Governance mode (override w/ permission) vs Compliance mode (no one, incl. root, can delete) + Legal Hold. Needs versioning.
Pre-signed URLsTime-limited URL granting temp GET/PUT using creator's credentials — share private objects.
Strong consistencyAll GET/PUT/LIST (incl. overwrites/deletes) are strongly consistent automatically, no extra cost.
