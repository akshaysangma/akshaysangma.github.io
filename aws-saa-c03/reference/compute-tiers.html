Compute — Tiers & Properties

EC2 families, purchasing options, Auto Scaling, load balancers, serverless & containers. Verified against AWS docs (Jun 2026).

EC2 instance families

Naming: [family][gen][options].[size], e.g. c7gn.xlarge = Compute, gen 7, graviton+network, xlarge.
CategoryLettersOptimized forWorkload
General PurposeT, MBalanced compute/memoryWeb servers, small DBs, dev/test
Compute OptimizedCHigh CPUBatch, media transcode, HPC, gaming
Memory OptimizedR, XLarge in-memory datasetsIn-memory DBs, caches, analytics
Storage OptimizedI, D, HHigh local-disk I/ONoSQL, data warehouse, Elasticsearch
AcceleratedP, G, Inf, TrnGPUs / ML chipsML training/inference, graphics
T-family (burstable) Earns CPU credits while idle below baseline, spends them to burst above. Great for spiky low-average workloads; bad for sustained high CPU.

Spot trap Spot is never the answer for databases, stateful or long-running critical work. "Can tolerate interruption" / "fault-tolerant batch" → Spot. Otherwise not.

Auto Scaling — policy types

PolicyTriggerCooldown?Best for
Target TrackingKeep metric at target (e.g. 50% CPU)NoDefault choice; most workloads
Step ScalingAlarm breach, stepped adjustmentsNoPrecise multi-step control
Simple ScalingSingle alarm thresholdYes (300s default)Basic / legacy
ScheduledTime / cron—Predictable patterns (business hours)
PredictiveML forecast (≥24h data)—Anticipate recurring spikes

Auto Scaling spans AZs for HA and uses launch templates. It replaces unhealthy instances and scales out fast / scales in conservatively (favours availability).

Load balancers (ELB)

TypeLayerProtocolsKey powerExam tell
ALB7HTTP, HTTPS, gRPCContent/path/host routing; targets EC2, IP, LambdaMicroservices, HTTP routing
NLB4TCP, UDP, TLSUltra-high throughput, ultra-low latency, static IP, PrivateLinkMillions of RPS, non-HTTP, static IP
GWLB3/4IPInsert 3rd-party virtual appliances (firewalls/IDS)Security appliance fleets
Classic (CLB)4/7TCP, HTTP(S)Legacy — avoid for new buildsLegacy only

Sticky sessions: ALB uses cookies (duration or app-controlled); NLB uses source-IP (flow hash). Need a static/elastic IP on the LB → NLB. Need to route by URL path → ALB.
