Resources

High-trust sources only. Knowledge in the lessons is drawn from here, not from memory.

Knowledge — Official (primary sources)

  • SAA-C03 Exam Guide (AWS, official) — The authoritative blueprint: domains, weightings, task statements, in-scope/out-of-scope service lists. Use for: deciding what to study and how much. The single source of truth — everything else is commentary on this.
  • SAA-C03 Exam Guide PDF — Printable version of the above. Use for: offline review of task statements.
  • Certification landing page — Logistics, exam fee, scheduling (Pearson VUE), official practice question set. Use for: booking the exam, official sample questions.
  • AWS Well-Architected Framework — The conceptual spine of the whole exam. Six pillars; four map directly onto the exam domains. Use for: the lens you apply to every scenario question.
  • AWS Skill Builder — Exam Prep: SAA-C03 (official, free tier) — AWS's own prep plan, including a free official practice question set and an Official Practice Exam. Use for: realistic question style and final readiness check.
  • AWS Documentation FAQs (per service) — e.g. S3 FAQ, EC2 FAQ, VPC FAQ. Use for: authoritative service limits, behaviours, and edge cases the exam loves.

Knowledge — Trusted third-party (to be vetted as we go)

  • Pluralsight / Adrian Cantrill course (paid) — widely regarded as the most thorough SAA-C03 video course. Use for: deep conceptual grounding if a topic won't stick. (Optional given timeline.)
  • Tutorials Dojo — practice exams & cheat sheets (paid, Jon Bonso) — the most recommended practice-exam bank; question style closely mirrors the real exam. Use for: timed practice and the "comparison of services" cheat sheets.

Wisdom (Communities)

  • r/AWSCertifications — high-volume subreddit of people sitting the same exams. Use for: study-plan critique, "is this resource still current", exam-day logistics, recent question-style reports.
  • AWS re:Post — AWS's official Q&A community. Use for: clarifying why a service behaves a certain way when docs are ambiguous.
