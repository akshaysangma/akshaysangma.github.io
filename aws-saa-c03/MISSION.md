# Mission: AWS Certified Solutions Architect – Associate (SAA-C03)

## Why
Pass the SAA-C03 exam within the next 1–2 months. The certification itself is the goal — the most efficient, reliable path to a pass, not an academic deep-dive. Learner already writes software and has some hands-on AWS exposure.

## Success looks like
- Score ≥ 720 (scaled 100–1,000) on the SAA-C03 exam — ideally a comfortable margin, not a squeaker.
- Reliably pick the *best* answer on scenario questions by reasoning through the Well-Architected lens (secure / resilient / high-performing / cost-optimized).
- Recall the right service for a given requirement (e.g. "decouple → SQS", "global static content → CloudFront", "managed relational with read scaling → RDS read replicas / Aurora").
- Sustain ≥ 85% on full-length practice exams before booking.

## Constraints
- **Timeline: 1–2 months, intensive.** Daily study, fast pace. Lessons must be short, high-leverage, and exam-weighted.
- **Pragmatic focus.** Prefer "what the exam tests" over exhaustive service coverage. Spend time proportional to domain weighting (Security 30% > Resilient 26% > Performant 24% > Cost 20%).
- Some hands-on AWS already — can skip absolute-beginner framing, but no assumption of breadth.

## Out of scope
- SAP-C02 (Professional) depth, CLI/SDK mastery, hands-on labs beyond what cements exam concepts.
- Services explicitly out-of-scope for SAA-C03 (see exam guide's out-of-scope list).
- Deep cost-accounting, billing console mechanics beyond what questions test.
